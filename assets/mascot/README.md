# Evi visual assets

Canonical project mascot: **Evi (伊维)**, a clean British Shorthair kitten.

Expected files:

- `evi.jpg` — clean full-body mascot, no accessories or props.
- `evi-identity-system.jpg` — turnaround, expressions, poses, palette, and silhouette reference.

See [../../docs/mascot.md](../../docs/mascot.md) for the identity rules.

These assets are repository branding and are intentionally excluded from the portable runtime Skill package.
