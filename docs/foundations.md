# Engineering foundations

This playbook synthesizes established public engineering guidance and treats it as input to judgment rather than a collection of absolute rules.

## Change and review practice

- Google Engineering Practices — https://google.github.io/eng-practices/
- Google Code Review Guide — https://google.github.io/eng-practices/review/
- Google Small Changes guidance — https://google.github.io/eng-practices/review/developer/small-cls.html

## Design and refactoring

- Martin Fowler, Refactoring — https://refactoring.com/
- Martin Fowler, Code Smell — https://martinfowler.com/bliki/CodeSmell.html
- Martin Fowler, YAGNI — https://martinfowler.com/bliki/Yagni.html
- John Ousterhout, A Philosophy of Software Design — https://web.stanford.edu/~ouster/cgi-bin/aposd.php
- Hyrum's Law — https://www.hyrumslaw.com/

## Testing

- Martin Fowler, The Practical Test Pyramid — https://martinfowler.com/articles/practical-test-pyramid.html
- Martin Fowler, Eradicating Non-Determinism in Tests — https://martinfowler.com/articles/nonDeterminism.html

## Security

- OWASP Application Security Verification Standard 5.0 — https://owasp.org/projects/asvs
- CWE Top 25 — https://cwe.mitre.org/top25/
- NIST Secure Software Development Framework — https://csrc.nist.gov/Projects/ssdf

## Compatibility

- Semantic Versioning 2.0.0 — https://semver.org/
- Hyrum's Law — https://www.hyrumslaw.com/

## Language guidance

- Python PEP 8 — https://peps.python.org/pep-0008/
- Go Code Review Comments — https://go.dev/wiki/CodeReviewComments
- Go Style Guide — https://google.github.io/styleguide/go/
- Rust API Guidelines — https://rust-lang.github.io/api-guidelines/

This repository paraphrases general engineering principles and links to authoritative sources for depth. It does not reproduce external checklists into the core playbook.
