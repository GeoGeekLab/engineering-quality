# Evi mascot identity

**Evi (伊维)** is the engineering-quality project mascot.

Evi is an original, ultra-cute **British Shorthair kitten** whose role is to make a rigorous engineering project feel approachable without turning engineering quality into decoration.

## Character idea

Evi represents the same qualities the Skill asks from coding agents:

- **careful** — inspect before changing,
- **trustworthy** — make claims that evidence supports,
- **gentle** — improve the codebase without unnecessary churn,
- **smart** — reason about contracts and failure modes,
- **calm** — prefer small, deliberate changes over noisy activity.

The name **Evi** is a short brand form inspired by **evidence**. The Chinese display name is **伊维**.

## Canonical appearance

Evi is based on a British Shorthair kitten with:

- dense silver-blue / cool gray fur,
- a very round head and chubby cheeks,
- oversized warm amber eyes,
- a small dark nose,
- a soft white muzzle,
- a small natural white heart-shaped chest patch,
- a slightly lighter belly,
- short sturdy legs and tiny rounded paws,
- a short, thick plush tail,
- compact, kitten-like proportions.

The expression should feel curious, gentle, attentive, and extremely cute rather than hyperactive.

## The most important rule: keep Evi clean

The canonical mascot is **the cat itself**.

Do not add:

- magnifying glasses,
- ID cards or badges,
- collars,
- clothing,
- hats,
- backpacks,
- tools,
- clipboards,
- shields,
- test tubes,
- laptops or code screens attached to the character.

Engineering-quality is communicated through Evi's personality and surrounding project copy, not by attaching engineering props to the animal.

For event artwork or illustrations, environmental objects may appear around Evi when useful, but they must not redefine the canonical character.

## Identity system

The project maintains two canonical visual assets:

```text
assets/mascot/evi.jpg
assets/mascot/evi-identity-system.jpg
```

The identity system covers:

- full-body hero appearance,
- front / side / back turnaround,
- normal, happy, curious, wink, surprised, and content expressions,
- sit, stand, walk, and lie-down poses,
- fur / eye / nose / inner-ear color references,
- the simplified silhouette.

## Usage

Use the clean full-body asset for:

- README brand moments,
- GitHub Discussions and release announcements,
- social cards when Evi is the focal character,
- community pages,
- project presentations.

Use the identity-system sheet as a reference for new derivative artwork, not as a small avatar.

For icons or very small sizes, derive a simplified head or silhouette while preserving the round face, amber eyes, and silver-blue coat.

## Tone

Evi should communicate:

```text
cute + careful + trustworthy + gentle + smart
```

Avoid making Evi aggressive, cyberpunk, armored, militarized, over-equipped, or visually busy.

## Relationship to the runtime package

Mascot assets are repository branding. They are **not** part of the portable Skill runtime ZIP and must not become a runtime dependency.

## Asset ownership and licensing

The mascot artwork is maintained as project artwork in this repository and follows the repository license unless a specific asset states otherwise.
